How Brand Scan works

Anyone can run a live scan: the site's own small backend calls TinyFish to read the brand's site, and Claude writes the guide from what TinyFish extracts. The Revolut, Spotify and Duolingo examples replay saved scans and use no credit. The code, the Python CLI (cli/brand_guide.py) and example outputs are in the GitHub repo.

SEARCH→ FETCH→ AGENT→ Brand guide The Agent only runs when Fetch can't read a page.

Why Fetch leads

In testing, the Agent got the font or hex code wrong on 2 of 3 sites. Fetch plus CSS parsing was right every time, so Fetch does the measuring and the Agent only fills gaps. Agent values are labelled in the guide.
